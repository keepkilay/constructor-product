# Constructor Product

Пример одной из деталок страниц: https://impulse-device.ru/products/impulse-kegel/

Кастомный конструктор продуктовых страниц для интернет-магазина на **1C-Bitrix**.

Репозиторий содержит шаблон компонента `bitrix:news.detail`, который используется для динамической сборки детальной страницы товара из набора связанных контентных блоков. Структура страницы управляется из административной панели Bitrix через свойства инфоблоков, без необходимости менять PHP-шаблон вручную.

Репозиторий: `keepkilay/constructor-product`

## Назначение проекта

Проект решает задачу гибкой сборки продуктовых лендингов внутри 1C-Bitrix.

Вместо жестко сверстанной страницы товара используется конструктор: администратор выбирает нужные блоки в свойстве товара, задает их порядок и наполнение через связанные элементы инфоблоков, после чего шаблон автоматически собирает полноценную страницу продукта.

Такой подход позволяет быстро создавать разные продуктовые страницы с индивидуальной структурой, визуальным оформлением, CTA-блоками, характеристиками, отзывами, аксессуарами и связанными товарами.

## Выбор цвета всей страницы

В шаблоне реализован выбор цвета всей продуктовой страницы через кастомное свойство инфоблока **“Выбор цвета”**.

Это свойство позволяет задавать индивидуальную цветовую схему для конкретного товара из административной панели 1C-Bitrix. После выбора цвета значение свойства используется в шаблоне для подстановки CSS-переменных, которые влияют на внешний вид страницы.

Через свойство **“Выбор цвета”** можно управлять:

- основным акцентным цветом страницы;
- цветом кнопок и CTA-элементов;
- цветом декоративных элементов;
- цветом некоторых фонов и визуальных блоков;
- общим визуальным стилем продуктового лендинга.

Благодаря этому для разных товаров можно задавать разное оформление без создания отдельных шаблонов и без изменения кода. Администратор выбирает нужный цвет в карточке товара, а страница автоматически применяет соответствующую цветовую схему.
